## Description
A simple task list web app where you can add tasks with a priority level (Low, Medium, High), put them as completed, and delete them.

## How to Run
1. Clone this repository.
2. Open `index.html` in a browser.
3. Enter task name, select a priority, and click "Add Task."

## Known Issues / Incomplete Features
- Tasks are not saved after refreshing the page
